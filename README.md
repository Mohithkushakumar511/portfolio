# Mohith Kusha Kumar — Personal Developer Portfolio

A luxurious, modern, and professional developer portfolio website for **Mohith Kusha Kumar** — Software Developer | Computer Science Enthusiast.

## 💎 Design System & Palette (Midnight Navy & Platinum)

- **Primary Background**: `#101827` (Midnight Navy)
- **Secondary Background**: `#1D2939` (Deep Navy)
- **Card Background**: `#243247` (Card Navy)
- **Platinum**: `#DCE3EA` (Headings and secondary highlights)

## 🚀 Key Architectural Features

1. **Dynamic Two-State Navigation Bar**:
   - **State 1 (Top of Page)**: Full-width, borderless, transparent header matching the hero aesthetic, with `MOHITH` branding on the left, centered navigation links (**About**, **Skills**, **Projects**, **Contact**), and accent-blue **Resume** button with **GitHub** and **LinkedIn** icons on the right.
   - **State 2 (Scrolled > 85px)**: Automatically transforms with a smooth 400ms transition into a centered, floating pill (`max-w-[1050px]`, `rounded-full`, `#354256` border, `#101827`/90 dark translucent background, backdrop blur, and elevated shadow).
   - Responsive mobile navigation drawer with zero layout jumps or flickering.

2. **Typography-Focused Hero Section**:
   - Primary Heading: **`MOHITH`** in luxury serif typeface.
   - Subtitle: **`SOFTWARE DEVELOPER | COMPUTER SCIENCE ENTHUSIAST`**.
   - Concise professional introduction highlighting software development, technology, and building practical digital solutions.
   - Primary action: **"View Projects"** button alongside direct GitHub, LinkedIn, Instagram, Discord, and Email quick links.

3. **About Section**:
   - Concise, natural, and confident narrative focused on software development, problem-solving, programming, web development, AI, and continuous learning.
   - Recruiter-focused and honest without mentions of semester or student status.
   - Seamless background transitions without rigid dividing lines.

4. **Technical Skills ("SKILLS")**:
   - 3 large premium cards:
     1. **LANGUAGES**: C, Java, Python, HTML5, CSS3, JavaScript
     2. **FRAMEWORKS**: React, FastAPI
     3. **TOOLS**: Git, GitHub, VS Code
   - Interactive hover glow with floating tooltips displaying technology names and architectural descriptions.

5. **Featured Projects (Compact, Text-Only Layout)**:
   - Exactly 3 authentic software systems:
     1. **01. AI Companion** — Personal intelligent assistant with context-aware dialogue and API orchestration.
     2. **02. Alpha Chatbox** — AI-powered chatbot with a robot-inspired UI, powered by FastAPI and Groq API.
     3. **03. Japan Tour Website** — Cinematic travel web platform showcasing Japanese destinations with a booking-oriented UI.
   - Compact text-first presentation with numbered labels, technology pills, and direct GitHub / Live Demo links without thumbnail clutter.

6. **Contact Section**:
   - Heading: **"Let's Build Something Together."**
   - Clickable links for Email, GitHub (`https://github.com/Mohithkushakumar511`), LinkedIn (`https://linkedin.com/in/mohithkushakumar`), Instagram (`https://www.instagram.com/m_x_hi_x_h/`), and Discord (`https://discord.com/channels/@me`).
   - One-click copy email button with visual confirmation.
